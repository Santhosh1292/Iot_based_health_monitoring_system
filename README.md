# IoT-Based Vital Monitoring and Voice-Assisted Medicine Identification System

## Description
This project monitors vital signs and assists visually impaired users by reading medicine labels aloud.

## Features
- Heart rate and temperature monitoring using ESP32
- Cloud data upload using ThingSpeak
- OCR-based medicine detection using OpenCV and EasyOCR
- Voice output using gTTS

## Technologies
ESP32, Python, OpenCV, EasyOCR

## How to Run
1. Upload ESP32 code using Arduino IDE
2. Run Python OCR script
